# Presentación web (8 min)

- `index_v3.html` — versión de 8 minutos (la más reciente). Con la tecla **S** se abren las notas del orador con el guion y los tiempos.
- `index_v2.html` — versión extendida (17 diapositivas).
- `index_v1.html` — primera versión.
- `index.html` — redirige a la v3.
- `guion_v3.md` — guion de la v3 con tiempos por diapositiva y respuestas a preguntas probables.
- `repo_figs/` — figuras generadas en este repositorio.
- `paper_figs/` — paneles de las Figs. 1–4 de Lewis S. et al., "Scalable emulation of protein equilibrium ensembles with generative deep learning", *Science* 389, eadv9817 (2025). © de los autores / AAAS; se incluyen solo con fines académicos de journal club.
