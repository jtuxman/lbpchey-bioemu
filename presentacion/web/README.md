# Presentación web (8 min)

Presentación en reveal.js: Parte I resume Lewis et al. (2025) y Parte II presenta los resultados de LBPCheY.

- `index.html` — la presentación. Ábrela en un navegador; con la tecla **S** se abren las notas del orador con el guion y los tiempos.
- `guion.md` — el guion con tiempos por diapositiva y respuestas a preguntas probables.
- `repo_figs/` — figuras generadas en este repositorio.
- `paper_figs/` — paneles de las Figs. 1–4 de Lewis S. et al., "Scalable emulation of protein equilibrium ensembles with generative deep learning", *Science* 389, eadv9817 (2025). © de los autores / AAAS; se incluyen solo con fines académicos de journal club.
